Switch profiles with a tap

Tap a profile in the Chats header to focus on its conversations. Tap the selected profile again to show all profiles. For work spanning several agents, open the Profile filter and choose the profiles you want together.

Hold a profile icon to open its Bot Chat directly.

Profile colors and the selected outline help you see which view is active. Administration also keeps its profile choices visible, so you can switch the agent whose settings you are editing.

Switch projects across profiles

Open the Project filter and choose a project or several projects to see their conversations together. It follows your profile selection; clear the Profile filter to choose projects across all profiles.

Hold New chat to reveal New project. Choose a name, color and searchable icon; its folder starts under the profile's default directory. Browse or create another server folder if needed. Edit project uses the same form; saving a different folder replaces its previous folder associations.

Project choices show their profile, so Research for your personal agent and Launch for your work agent can sit in the same view. Chats without a project have their own profile group. To remove a chat from a project, open Move to project, use the cross in Current project, and confirm. Its messages stay intact.

Build your chat view

Use Group by to arrange chats by project, profile, status or updated date. Filter by profile, project and status to decide which chats belong in that view.

Sort by orders chats by time, status, tokens or cost. Show details lets you choose the profile, time and usage information beside each conversation.

Choices apply immediately and are remembered for each connection on your phone. Tap an ordinary chat's title to rename it; the sparkle suggests a name from the conversation for you to review before saving.
