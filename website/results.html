Markdown, code
and file previews

Read formatted Markdown

Headings, emphasis, lists and quotes keep their formatting. Wide tables become stacked header/value rows on narrow screens. Use the table icons to choose rows or a wrapped grid.

A table's full-screen icon opens conversation reading mode, hiding the composer without losing your draft. Use the same icon or Android Back to return. Landscape combines the title and context into one header row, leaving more room for the conversation. Set text size and light or dark appearance in App settings.

Copy code and wrap long lines

Each code block has a language label and its own copy control. Copy just the code, or switch between scrolling and wrapping long lines.

Identified source languages have syntax coloring, including large files. Selection and copying retain the original text. Live code stays plain while the reply streams.

Copy messages and listen to replies

Use the message copy action to copy a whole answer without selecting it by hand. Read aloud plays the reply; App settings lets you choose on-device or Hermes speech processing.

Preview, save and share output files

Open files from the answer to preview Markdown, HTML, PDFs, diagrams and supported media. Markdown previews switch between formatted content and exact source with an icon in the toolbar. Save a report or share an output file through Android.

Images appear in the reply with a download control. Tap an image to zoom the original. File previews depend on the format and what Hermes returns.
