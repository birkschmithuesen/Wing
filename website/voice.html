Talk using your ChatGPT subscription

Use GPT Live with your ChatGPT subscription to talk with your Hermes agent, ask it to do work and hear the results. Separately billed OpenAI API access is also available.

Start from an ordinary chat or a Bot Chat. Your call stays attached to that conversation when you navigate elsewhere. Group discussions do not offer live voice.

Both account modes require the Wing plugin for Hermes, installed and enabled on your server in the profile you are chatting with. Updating the Android app alone does not install it.

Set up voice for your profile

  1. Install and enable the Wing plugin for Hermes in the profile you use.
  2. Open App settings → Voice → Live conversation. Choose ChatGPT subscription or OpenAI API, then select your GPT-Live voice.
  3. Open a connected ordinary chat or Bot Chat and tap Start voice conversation, the waveform beside the microphone in the message field.
  4. Allow microphone and notification access. Allow Bluetooth access if you use a headset.

Subscription mode uses that profile's OpenAI Codex sign-in with voice access and your ChatGPT plan's voice allowance. API mode uses the profile's OpenAI voice credentials and bills its API account separately. Wing never switches billing modes automatically; a changed choice applies to the next call.

Choose and preview a voice

In App settings → Voice, choose GPT-Live voice below the Live conversation mode. Wing remembers separate subscription and API choices on this phone and includes them in settings backups. Changes apply to your next call; they do not change Android read-aloud voices or Hermes profile defaults. Use the current Wing plugin for voice selection.

Tap the speaker beside the picker to preview a subscription voice, then Stop to end the sample. These bundled recordings play offline, with no microphone access, server connection or voice usage charge. Changing a setting, leaving the page or putting Wing in the background stops playback. API voice previews are not available yet.

Keep talking while you move

A compact floating call card stays above the app as you navigate. Its main row shows the original chat title, call duration, mute, audio routing and End voice. Calls can continue while you switch apps or lock your phone. The Android notification also offers Mute and End voice.

In the original chat, read spoken text directly in the conversation. Enter another chat or group and the card adds a lower row with captions and Return to voice chat, the speech bubble with a waveform. The call still belongs to the original chat; browsing a group does not start a group call.

Captions start off. When enabled, they scroll within two lines beside the controls. Returning to the voice chat keeps the call connected, hides the extra controls and resets captions off. Opening a list or menu alone does not reveal them.

Speak with the selected profile's identity and saved context. When you ask for work, GPT Live delegates a text request to your normal Hermes agent, which runs the tools and returns a result. Handle approvals and questions in the originating chat.

Talking over a spoken reply or ending voice leaves accepted Hermes work running. Say “stop the task” or use the chat's Stop control to cancel work. Incoming calls or loss of audio focus end the voice session.

Know what is saved and shared

Spoken entries marked Not saved to Hermes can be read and copied while Wing runs, including after ending a call or switching chats. They disappear on app restart. Complete spoken exchanges are not yet saved to Hermes's shared history or memory because of a current Hermes limitation: there is no supported operation Wing can use to record externally spoken turns without asking Hermes to generate another reply.

The exact upstream request is Hermes issue #121045: record externally conducted conversation turns. Its earlier implementation, PR #121056, was closed without merging. The related PR #87053: persist plugin chat messages remains open and unmerged as of 9 November 2026. These are proposals, not an available fix for Wing's full spoken history.

Hermes saves delegated task requests and results normally. In the current chat, results appear under expandable Hermes task details, separate from GPT Live's spoken answer.

Live audio goes directly to OpenAI; relevant chat context and task results also reach the voice service. Provider credentials remain on Hermes. Read the privacy policy for data handling.

Dictation and read-aloud remain available

The microphone beside the waveform records speech into an editable draft for you to review before sending. Read aloud plays an existing assistant reply. These are separate from a live conversation and do not require the Wing plugin.

Choose on-device or Hermes processing for each under App settings → Voice. See the complete voice guide for device requirements.
