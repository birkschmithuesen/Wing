Watch tools and delegated agents

As an answer streams, readable reasoning separates collapsed Activity runs. Open a run to inspect its tools. Its elapsed timer counts upward until the next reasoning block arrives, then stays fixed.

The Tasks / Subagents bar above your draft opens current work. Swipe up once to open compactly, up again to expand, and down to close. Swipe sideways between the drawers; the summary stays visible while rows scroll.

Open a subagent to read its task, conversation and available live output. Where supported, steer it or request interruption from the same view; your parent chat and draft stay selected.

Completed children move into the parent answer's saved Activity when its turn ends; unfinished background agents remain in the current drawer. Past answers retain received tools, reasoning and agent results. Historical agents have no live controls.

Steer, queue, stop or fork

To change direction while the agent is working, type an instruction and hold the send control. Slide to Steer to send it now, or Queue to save it for later. Hermes runs accepted queued messages even after Wing disconnects. Edit a still-queued message to replace it at the tail, or use its supported steer and cancel controls.

Stop interrupts the active run. It appears in an empty composer; typing brings back Send and the held actions. You can also edit saved messages or regenerate answers. Restore in a saved user message's footer asks for confirmation, then removes later history and reruns that prompt. Your separate draft stays intact and queued follow-ups pause for review.

To explore another direction, choose Fork from a selected saved answer's footer. Wing creates a separate chat through that answer, keeping the original conversation available. Fork is available once the source chat is idle. The new chat opens immediately with loading feedback; later replies in the original are not included.

Inspect tool requests and results

Expand a tool call to see what was requested and what it returned. Code execution shows code and output. Other calls can show file contents, changes, search matches or structured data.

Copy the code or output separately, wrap long lines, or open a full view. File and image results have preview and share actions. Raw details shows the supplied inputs and output.

Completed questions and approvals stay in Activity with their supplied answers and outcomes. A request answered on another client no longer remains open in Wing. Secret response values are not saved in that history.

Timeline includes supplied reasoning. A saved reply's collapsed Activity header can show the time from its prompt to the final answer, including thinking and tool work. Individual tools show measured durations when available.

Talk while your agent works

Use GPT Live with your ChatGPT subscription, or choose separately billed OpenAI API access. Start a conversation with the waveform icon beside the microphone in a connected ordinary chat or Bot Chat. Group discussions do not offer live voice. Speak with the selected profile's identity and saved context, ask Hermes to do work, and hear the result. Approvals and questions stay in the originating chat. The call remains attached to that conversation when you browse elsewhere.

Choose ChatGPT subscription or OpenAI API in App settings → Voice → Live conversation. Subscription mode uses that profile's ChatGPT sign-in and voice allowance; API mode has separate API billing. Both need the Wing plugin for Hermes installed and enabled on your server for the same profile.

The compact floating call card shows the original chat title, duration, mute, audio routing and End voice. Enter another conversation to reveal its caption toggle and Return to voice chat. Returning hides those extra controls and resets captions off; the call stays connected.

Choose a GPT-Live voice for each billing mode in App settings. Subscription voices have offline previews; API previews are not available yet. Choose and preview a voice.

Calls can continue while switching apps or locking the phone. Allow microphone and notification access, plus Bluetooth access for a headset. The Android notification also offers Mute and End voice.

Ending voice or talking over a reply leaves Hermes work running. Say “stop the task” or use the chat's Stop control to cancel work. Incoming calls or loss of audio focus end the voice session.

Spoken entries marked Not saved to Hermes stay available while Wing runs and disappear on app restart. Full spoken history awaits a supported Hermes recording operation; see the limitation and upstream proposals. Hermes task results are saved normally, under expandable Hermes task details. Audio goes directly to OpenAI, along with relevant context and results; credentials stay on Hermes.

Voice setup, controls and data handling

Compose with files, voice and skills

Use Attach file to choose Camera, Photos or Files. Chats, Bot Chats and groups share the picker and image preview. You can also send content to Wing from another Android app. Review attachments before sending.

Dictation writes into an editable draft, so you can check and change the words first.

Type / after a space or on a new line to choose a skill while writing. Wing highlights the inserted skill name and loads its instructions when you send the message.

Preview a skill from the suggestions or open it in chat to read its instructions and reference documents. Type @ to browse server files and folders; selected files are read when the message sends, and unavailable references pause it for correction.

Make room in a long conversation

In an idle chat, send /compress --preview to inspect the plan, then /compress or /compact to apply it. Wing refreshes the conversation and shows what changed. The context popup identifies a configured maximum when Hermes supplies it.

When the agent asks several questions, review and answer them together before confirming. Eligible cut-off replies offer Continue, so you decide when to ask for the next part.

For code work in a supported local workspace, open Chat actions → Git review to inspect changed files and staged changes, then copy a line or hunk reference. Review is read-only.

Return to your draft

Unsent text and attachments stay with their conversation when you switch chats, open another screen or restart Wing.

Reconnect to ongoing work

Work accepted by Hermes can continue while your phone is disconnected. Reconnect to follow it or send another instruction. New messages and live controls need a connection.
