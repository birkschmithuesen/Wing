Create or edit a schedule

Schedule a daily research brief or a one-off task for a profile. Open Scheduled tasks in Administration, start from a server template or write your own instructions, then choose when it runs.

Choose the model and where results go, including a discovered bot group. Mention group members in the result when you want them to continue the work; a post without mentions is informational. Save on server stores results on Hermes.

Choose a schedule timezone or use the profile default. Set a late-run window and decide whether missed work gets one catch-up run or is skipped. Run timestamps are shown in phone time.

Run, pause or stop work

Search the list or filter by All, Active, Paused or Needs attention. Open a task to see its instructions, next run and recent history.

Pause schedule prevents future runs. Stop run requests cancellation of current work and leaves its schedule enabled, including while Run now is waiting. Cancellation can take time; the run history records the outcome. A paused task asks you to resume before running immediately.

Review recent runs

Open an agent run to read its conversation. Script runs show the returned status, timestamp and output or error in the task details.

You can leave the task details while a run continues, then return to check the result. For a failed task, copy its details or open an investigation chat with the responsible profile.
