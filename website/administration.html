Set models and agent instructions

Choose a profile in the header, then edit its description and instructions. Choose model defaults, reasoning options where available, and memory settings.

Profile defaults apply to new conversations. In a chat's model picker, Use profile default removes that chat's explicit choice. Set a separate default for new subagents or let them inherit their parent's model.

You can open the same editors from Bot settings.

Manage skills, providers and connectors

Open Skills and tools to browse installed skills and read their instructions. For a local or learned skill, open its actions and choose Edit instructions; use the checkmark to save. Bundled skills are read-only. Use a skill's lock action to prevent agent edits while keeping your own editing rights.

Discover more skills through the official Hub, and check which skills and tools still need setup. In Agent plugins, manually update installed plugins and inspect each updated, skipped, failed or review-needed result.

Manage model-provider access and MCP connectors for the selected profile. Connectors give the agent access to external tools and data. Cached runtime status shows reported connection or sign-in problems separately from Test connection. Supported hosted accounts appear in Connected apps, with separate names and authorization for each account.

Find a setting and review changes

Search Administration to jump to a setting. Editors show the profile you are changing and keep unsaved edits if a save fails or its outcome is uncertain.

Wing reads back settings to confirm changes. A definite refusal shows the server's explanation and keeps your edits available. After an uncertain response, refresh and review before saving again. Controls depend on what the connected Hermes server makes available.

In connection details, Versions & updates checks Hermes updates, lets you choose Stable releases or Main branch, and confirms the target before updating. Progress appears immediately; logs follow automatically with newest lines first and their own scroll area.
