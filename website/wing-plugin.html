What the Hermes plugin adds

The Wing plugin for Hermes is an optional, open-source plugin installed on your Hermes server. It gives the Wing Android app two extra capabilities:

  • GPT Live conversations using your ChatGPT subscription or separately billed OpenAI API access, with your selected profile's identity and context.
  • Email draft cards with recipients, subject and body, ready to open in your phone's email app.

The plugin is separate from the Android app: an APK update does not install or enable it. Ordinary text chats, dictation and read-aloud work without it. Both live voice modes and email draft cards require it in the profile where you use them.

Use current upstream Hermes, at least 0.23.0, with its dashboard/gateway reachable from Wing, and Wing 1.4.1 or newer. The plugin runs on stock Hermes without a core patch. Its version is separate from the Android app's version.

Install and enable it from Wing

  1. Connect to the server you want to change. Open App settings → Hermes → Wing plugin.
  2. Review installed versions and the latest release, then expand Profiles.
  3. Use the action beside your profile to install, update or enable the plugin. You can instead install or update across all profiles. Review any confirmation before proceeding.
  4. Check each profile's result, follow any Hermes restart instruction, and start a new chat so newly enabled tools are available.

Install and enable it in every profile where you want these features. Enabling it in the default profile alone does not enable it elsewhere. Opening the manager never installs or updates anything automatically.

Full spoken conversations are not yet saved to shared history or memory because Hermes lacks the supported recording operation Wing needs. The plugin does not remove that limitation. Hermes saves delegated task results normally. History limitation and upstream proposals.

For voice, next choose your account mode in App settings → Voice → Live conversation. Continue with voice setup.

Draft an email, then send it from your phone

Enable the plugin's wing_email toolset for your profile and start a new chat. Ask Hermes to draft an email. Its draft tool returns a card showing recipients, subject and body.

Tap the envelope-arrow action to open the complete draft in your chosen Android email app, including any CC or BCC recipients. Review, edit and send there. The plugin does not send email or need access to your email account.

Ask for a revision to create a new version; older cards retain their original contents. Drafts stay in the selected Hermes profile. Email cards need neither an OpenAI account nor a voice subscription.

Update and recover per profile

The manager shows installed versions, the latest GitHub release and readiness. Refresh reads installed state and checks releases again. A failed profile does not block actions on another profile whose state has been verified.

New installations use the exact published release commit. Replacing an existing pinned copy asks you to confirm the target and affected profiles. An unpinned copy follows its configured source, which may lag GitHub's latest release.

Network problems, timeouts, rate limits and invalid release responses have distinct explanations. Installed information remains visible when a release check fails. After an uncertain operation, refresh before retrying and inspect each profile's result.

Read the full plugin setup and recovery guide for source pinning, reinstall confirmations and leaving settings during an operation.
